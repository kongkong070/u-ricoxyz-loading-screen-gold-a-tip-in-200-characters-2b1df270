One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer.

> Tip: while this loads, your agent is re-reading the ticket, the docs, and your last message — hunting for the part where you changed your mind.

`main.ts` (Node 22) writes the tip to `/output/entry.txt`. Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
